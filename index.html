      Measurement methodology and implementation scope

      The host uses the existing reference encoder. Physical Cortex-A9 firmware maps and demaps encoded bits and returns I/Q symbols over UART. The actual returned demapped bits are sent to the selected decoder. This is digital baseband loopback — not RF, OFDM, channel estimation or an ADC/DAC link.

      Decoder timing uses three repetitions after one warm-up with data resident on the board. UART, modem and trace replay are excluded and reported separately. Stage times overlap. CPU cycles are elapsed CPU clock cycles, not retired instructions. LUT/BRAM/DSP describe allocation from implementation reports, not runtime utilization.

      PL places all five decoder algorithms in fabric; ARM still handles modem, UART, control and DMA. Hybrid places Helical and PRBS on PS and Viterbi, Block and Reed–Solomon on PL. Comparison uses the same message, coding profile and prepared frame, running PS → PL → Hybrid. Shared reference agreement does not prove LDACS standards conformance or a radio deadline. Power, CPU load and energy efficiency are not instrumented.
